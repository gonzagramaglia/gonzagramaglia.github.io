# Full Stack Developer

## Independent Professional (2024 – Present)

Transition from IT Operations to architecting and deploying custom web solutions from scratch. My work unites agile full-stack development with a strong focus on operational resilience, security hardening, and cloud scalability.

---

### Early Projects & Mentorship
My path into software engineering began under the direct mentorship of a senior engineer with over a decade of industry experience. This period was essential for cementing software design principles and clean architecture patterns within real-world production environments.

During this stage, I engineered the responsive user interface for an apparel e-commerce platform, optimizing for loading speeds, accessibility, and fluid layouts. In parallel, I developed a full-stack internal management platform for a used mobile device enterprise: a system built for comprehensive inventory tracking, device provenance, and cash-flow management, where I implemented strict relational data integrity, transaction safety, and automated financial accounting.

---

### Civic Infrastructure: Electoral Transparency (Fiscalicemos)
One of my most significant engineering challenges was designing and deploying the digital infrastructure for a civic election monitoring and transparency initiative in Córdoba, built to safeguard democratic integrity during high-stakes election cycles.

The initial milestone was **[Fiscalicemos](https://www.lalibertadavanzacba.com/)** ([Source Code](https://github.com/gonzagramaglia/fiscalicemos)), a secure web platform engineered in **TypeScript** to orchestrate the onboarding, identity verification, and polling station assignments for thousands of volunteer observers. The core challenge required balancing a friction-free onboarding UI with strict input sanitization, form validation, and secure data storage.

Following this launch, I played a key role in the frontend development of the initiative's official vote-tally mobile application, designed for real-time ballot recording and anomaly detection against official electoral records. Beyond delivering an intuitive mobile experience for poll workers, I collaborated directly on backend concurrency bottlenecks, cloud infrastructure scaling, and security hardening, ensuring zero downtime under peak election-night traffic bursts.
